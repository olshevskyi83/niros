# Music Generation Flow

## Phases

1. Arrival
2. Safety / grounding
3. Opening emotional access
4. Deepening
5. Peak / processing
6. Return
7. Integration

## Prompt requirements

- therapeutic objective
- emotional intensity
- instruments / textures
- tempo range
- voice presence
- avoided elements
- duration
- cultural context

## Example prompt skeleton

```yaml
phase: return
objective: restore safety and coherent breathing
intensity: low_to_medium
tempo: 60-75 bpm
texture: warm, spacious, non-intrusive
avoid: harsh percussion, sudden changes, lyrical commands
```

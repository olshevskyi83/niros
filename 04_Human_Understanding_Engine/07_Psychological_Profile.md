# Psychological Profile

The psychological profile is a structured representation of the person for downstream planning.

## Profile sections

- Identity-neutral preferences
- Declared problem
- Main themes
- Emotional regulation pattern
- Avoidance / approach patterns
- Relationship context
- Sleep and energy
- Risk flags
- Readiness for session
- Therapeutic targets
- Music sensitivity / preferences
- Contraindications / caution notes

## Output principle

The profile should be concise enough for AI use but clear enough for human review.

## Example structure

```yaml
profile_id:
created_at:
declared_problem:
confirmed_targets:
confidence:
risk_flags:
readiness:
recommended_next_step:
```

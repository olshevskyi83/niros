# NIROS Core Concept v2

NIROS does not try to create an AI psychologist.

NIROS does not replace psychotherapy.

NIROS does not diagnose.

NIROS is an engineering system for personalization of psychological interventions.

## Core hypothesis

If a psychological intervention is precisely matched to a person's Digital Psychological Fingerprint during a period of increased neuroplasticity, it may be more effective than generic scripts or universal therapeutic texts.

This is a hypothesis to test, not a proven claim.

## Core pipeline

```
Human Language
↓
Semantic Understanding
↓
Psychological Signals
↓
Digital Psychological Fingerprint
↓
Therapeutic Strategy
↓
Therapeutic Language
↓
Music / Voice / Text
```

## Key principle

LLM does not do psychology.

LLM helps interpret human language.

NIROS does psychology-level reasoning through its own structured modules:

- semantic facts
- pattern detection
- coverage
- fingerprint
- strategy
- readiness
- pattern-person fit

## Therapeutic Language Engine

TLE is future R&D.

It does not belong to current MVP core.

TLE analyzes therapeutic language sources and produces structured Universal Therapeutic Patterns.

It does not decide what to use for a person.

NIROS decides pattern fit based on Digital Psychological Fingerprint.

## Music Layer

Music is not the therapy itself.

Music is a delivery format for psychological intervention.

Icaros are one possible output format, not the whole system.

# Clinical Scales Reference

NIROS may use validated questionnaires as structured signals, but the first MVP should not pretend to be a clinical instrument unless properly validated.

## Candidate domains

| Domain | Examples of scale families | NIROS use |
|---|---|---|
| Depression | PHQ-style | Symptom screen / severity context |
| Anxiety | GAD-style | Anxiety pattern detection |
| PTSD | Trauma symptom screens | Risk and target clarification |
| Alcohol / substances | AUDIT-style | Contraindication and support planning |
| Sleep | Insomnia screens | Recovery and arousal context |
| Functioning | Work/social function | Impact assessment |

## Rule

Scales are inputs to the hypothesis engine, not final truth.

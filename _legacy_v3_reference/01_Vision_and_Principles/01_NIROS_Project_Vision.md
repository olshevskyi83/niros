# NIROS Project Vision

NIROS is a research operating system for personalized psychedelic session support.

The long-term vision is to create a structured platform that can help investigate how psychological profile, worldview, voice, music, language, timing, physiological state, and session structure interact during psychedelic experiences.

## Foundational idea

The therapeutic or transformative potential of psychedelic sessions may depend not only on the molecule, but also on the context around the experience:

- preparation;
- facilitator presence;
- voice;
- rhythm;
- music;
- language;
- metaphors;
- silence;
- timing;
- safety;
- integration;
- participant expectations;
- personal history;
- worldview.

NIROS exists to make these variables explicit, structured, and researchable.

## Core shift

The project is not about creating a mystical AI or an automated psychedelic guide.

The project is about creating a **traceable research system**:

```text
profile + safety + evidence + method + module + session timeline + outcomes
```

## Practical ambition

The founder does not need to be a scientist to start the project. The system itself must be built to reduce unsupported claims, force documentation, separate hypothesis from evidence, and make later collaboration with researchers and clinicians possible.

## Long-term goal

NIROS should become a durable research platform that can:

- organize open scientific knowledge;
- generate personalized session-support materials;
- document safety decisions;
- capture session timelines;
- compare outcomes;
- generate research hypotheses;
- support future clinical or academic collaboration.

## Public language

Use cautious wording:

- "research platform"
- "personalized session support"
- "psychedelic-assisted context analysis"
- "hypothesis generation"
- "outcome tracking"

Avoid unsupported claims:

- "cures"
- "treats"
- "heals"
- "guaranteed results"
- "AI therapist"
- "digital shaman"

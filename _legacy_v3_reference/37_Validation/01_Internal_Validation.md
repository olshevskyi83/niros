# Internal Validation

## What to test first

- questionnaire completeness,
- declared vs confirmed target accuracy,
- user agreement with AI summary,
- safety flag detection,
- music/profile matching,
- facilitator usability.

## MVP metrics

- completion rate,
- user correction rate,
- profile confidence,
- safety false positives,
- safety false negatives,
- session satisfaction,
- integration adherence.

# DR-005: Local First Data Strategy

## Context

Sensitive profile data should be stored locally whenever possible during MVP.

## Decision

Accepted as a guiding project decision.

## Consequences

- Shapes system architecture.
- Shapes prompts and documentation.
- Reduces risk of unsafe claims.

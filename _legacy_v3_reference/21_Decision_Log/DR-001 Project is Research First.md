# DR-001: Project is Research First

## Context

The platform is documented and built as research tooling, not as a consumer treatment app.

## Decision

Accepted as a guiding project decision.

## Consequences

- Shapes system architecture.
- Shapes prompts and documentation.
- Reduces risk of unsafe claims.

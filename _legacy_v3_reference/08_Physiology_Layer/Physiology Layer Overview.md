# Physiology Layer Overview

## Purpose

Physiology provides context for emotional and autonomic activation during profile building and sessions.

## MVP sensors

- heart rate;
- HRV if available;
- respiration if available;
- optional blood pressure outside session.

## Avoid overclaims

Heart rate does not prove truth, trauma, or diagnosis. It only provides a signal of arousal and regulation.

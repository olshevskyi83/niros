# Ayahuasca / DMT Research Module

## Purpose

A future module for research-context analysis of ayahuasca/DMT-related session support, safety screening, cultural context, voice/music structure, and outcome tracking.

## Status

Not part of MVP v2.0 implementation.

## Hard boundaries

This module must not include:

- recipes;
- plant ratios;
- brewing procedures;
- extraction steps;
- dosing guidance;
- medication-combination instructions;
- instructions for unsupervised use.

## Allowed scope

- safety-risk categories;
- MAOI-related caution framework without actionable combinations;
- contraindication screening fields;
- cultural and anthropological context;
- voice/vocal structure analysis;
- integration tracking;
- adverse event logging;
- research questions.

## Cursor implementation notes

Do not implement generation features for this module until Safety Engine v2 and Knowledge Base v2 are stable.

Any generated content from this module must pass a stricter safety validator.

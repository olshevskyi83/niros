# Dynamic Decision Trees

## Purpose

Decision trees define what the system should do when the participant's state changes.

## Examples

If arousal is too high:

- reduce intensity,
- remove lyrical density,
- add grounding voice,
- slow rhythm,
- add breath-oriented segment,
- alert facilitator if needed.

If emotional access is too low:

- increase warmth,
- use safer memory prompts,
- reduce pressure,
- extend trust-building phase.

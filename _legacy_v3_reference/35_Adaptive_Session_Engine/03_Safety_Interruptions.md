# Safety Interruptions

## Purpose

Define when NIROS should interrupt or de-intensify a session.

## Triggers

- panic escalation,
- dissociation signs,
- severe distress,
- physiological outlier,
- user stop command,
- facilitator stop command,
- contraindication discovered.

## Required behavior

Safety interruption must be calm, non-alarming, and grounding.

The system should never shame the participant for needing to stop.

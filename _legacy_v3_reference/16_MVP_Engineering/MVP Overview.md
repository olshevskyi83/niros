# MVP Overview

## MVP goal

Build a working local-first research prototype that can:

1. collect questionnaire answers;
2. record voice answers;
3. transcribe audio;
4. generate a structured profile;
5. retrieve research evidence;
6. generate a personalized script;
7. export Markdown and audio-ready text.

## Suggested stack

- Python;
- FastAPI or Streamlit;
- SQLite/PostgreSQL;
- ChromaDB/Qdrant;
- Whisper;
- OpenAI API or local LLM;
- Docker;
- Obsidian export.

# PTSD Protocol

## Primary targets

- intrusive memories,
- hypervigilance,
- avoidance,
- shame,
- body threat response,
- emotional numbing,
- relational mistrust.

## Intake focus

- trauma sensitivity,
- current safety,
- dissociation,
- grounding capacity,
- triggers,
- support network,
- prior therapy.

## Rule

PTSD protocols require conservative pacing and strong safety/grounding layers.

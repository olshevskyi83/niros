# Clinical Protocols Index

This folder converts clinical modules into structured protocol families.

A clinical protocol is not a medical treatment claim. It is an evidence-aware personalization framework that defines:

- intake questions,
- exclusion and caution rules,
- likely therapeutic targets,
- session tone,
- music strategy,
- integration focus,
- outcome metrics.

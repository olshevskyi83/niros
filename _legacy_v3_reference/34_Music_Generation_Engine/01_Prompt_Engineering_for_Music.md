# Prompt Engineering for Music

## Purpose

Generate prompts for AI music tools or human composers using the confirmed therapeutic target.

## Prompt inputs

- confirmed target,
- emotional arc,
- worldview profile,
- symbolic preferences,
- language,
- voice preference,
- cultural boundaries,
- contraindicated themes,
- session phase.

## Rule

Music prompts must avoid unsupported cure claims and manipulative religious framing unless the user's worldview explicitly supports that symbolism.

# Session Protocol Overview

## Purpose

The Session Engine structures preparation, session delivery, and integration.

## Stages

1. Screening.
2. Preparation.
3. Consent.
4. Baseline measurements.
5. Session protocol.
6. Immediate debrief.
7. Integration.
8. Follow-up outcomes.

## Safety

The platform must not encourage unsupervised psychedelic use. Clinical deployment requires legal compliance and professional supervision.

# Voice Analysis Overview

## Purpose

Voice analysis helps detect emotional load, uncertainty, avoidance, calmness, activation, and shifts between topics.

It must **not** be framed as lie detection.

## Features

- speech rate;
- pauses;
- pitch range;
- intensity;
- vocal tremor;
- topic-linked emotional shifts;
- silence duration;
- self-corrections.

## Correct interpretation

If a person says a topic is neutral but voice and physiology show activation, the correct label is:

> This topic may carry emotional load and needs gentle follow-up.

Not:

> The person is lying.

# NIROS Research OS v3

NIROS — NeuroIcaro Research Operating System — is a research-first architecture for building individualized, evidence-aware therapeutic audio/session systems.

This vault is the single source of truth for:

- scientific foundations,
- system architecture,
- clinical modules,
- voice-first intake,
- sensor-assisted profiling,
- AI interpretation logic,
- adaptive session design,
- music and scenario generation,
- safety, validation, ethics, and implementation.

## v3 focus

The v3 vault adds a stronger operational layer:

1. **Voice-first questionnaire** — the participant can answer naturally by speaking, not just filling forms.
2. **Sensor layer** — HRV, heart rate, respiration, sleep/fatigue, motion, and possible wearable signals become context, not diagnosis.
3. **Problem confirmation loop** — the user states the problem first; NIROS then checks whether the deeper profile supports, refines, or contradicts it.
4. **Idea intake workflow** — new ideas go into a dedicated inbox so ChatGPT/Cursor can process them consistently.
5. **SDK and implementation contracts** — future code should follow explicit schemas and module contracts.

## Recommended workflow

Use `00_HOME.md` first.

# Psychological Model Overview

The psychological model organizes participant data into practical dimensions for personalization.

## Core dimensions

- personality tendencies;
- threat sensitivity;
- control style;
- attachment style;
- worldview;
- body relationship;
- pain meaning;
- symbolic language;
- avoidance patterns;
- preferred support style.

## Output

The model should produce script constraints, not clinical labels unless validated by qualified professionals.

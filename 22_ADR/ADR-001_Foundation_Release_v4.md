# ADR-001 — Foundation Release v4

## Status

Accepted

## Context

The project was expanding rapidly. Without a stable architecture, it risked becoming an endless research cloud.

## Decision

Freeze the top-level NIROS architecture at v4. Future changes must fit existing modules or require ADR approval.

## Consequences

- Cursor can rely on stable paths.
- Obsidian navigation remains coherent.
- New ideas go through Inbox and Workbench.
- The project avoids uncontrolled expansion.

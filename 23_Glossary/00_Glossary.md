# NIROS Glossary

## Declared Problem

The user's own description of why they came.

## Confirmed Therapeutic Target

A working target inferred after structured exploration. Not a diagnosis.

## Human Understanding Engine

The module that converts conversation, structured questions, and optional sensors into a human profile.

## Adaptive Interview

A structured conversation that changes questions based on previous answers while staying inside a state machine.

## AI Hypothesis

A possible explanation with confidence, evidence for, evidence against, and next-best-question logic.

## Sensor Fusion

Combining physiological signals with context to produce soft state estimates.

## Music Objective

A functional goal for music, derived from therapeutic targets.

## Anti-NASA Rule

The discipline rule that prevents the project from expanding into everything.

# Big Five Data Model

## Status

Implementation Design

Sprint 002

---

# Purpose

This document defines the internal data representation of the Big Five Module within the NIROS Psychological Engine.

The objective is not only to store personality scores, but to provide standardized psychological signals that can be consumed by the NIROS Reasoning Engine and integrated with outputs from all other assessment modules.

The data model is intentionally designed to be compatible with future modules including Attachment, Emotion Regulation, Trauma, Suggestibility, Absorption, Values, Cognitive Style, Motivation, Mental Health Screening and Conversation-based AI Assessment.

---

# Design Principles

The data model should be:

- Modular
- Explainable
- Deterministic
- Extensible
- Source-aware
- Confidence-aware
- Versioned
- Independent from UI
- Independent from implementation language

Every NIROS assessment module should expose its results using the same conceptual structure.

---

# Psychological Signal

The fundamental unit of psychological information inside NIROS is the Psychological Signal.

A Psychological Signal represents one measurable psychological characteristic generated by an assessment module.

Examples include:

- Openness
- Extraversion
- Attachment Anxiety
- Emotional Suppression
- Cognitive Flexibility
- Suggestibility
- Trauma Severity
- Psychological Flexibility

Every module contributes one or more Psychological Signals.

The Reasoning Engine never consumes raw questionnaire answers directly.

Instead, it operates on Psychological Signals.

---

# Signal Components

Every Psychological Signal contains the following information.

## Module

The module responsible for generating the signal.

Examples:

- Big Five
- Attachment
- Trauma
- Emotion Regulation
- Conversation Assessment

---

## Signal Name

The psychological construct being measured.

Examples:

- Openness
- Agreeableness
- Attachment Anxiety
- Emotional Awareness

---

## Value

Represents the estimated strength of the construct.

Default scale:

0–100

Where

0 = extremely low

100 = extremely high

---

## Confidence

Confidence represents how reliable NIROS considers the estimated value.

Confidence is expressed as a value between

0.0 – 1.0

Confidence is affected by:

- response consistency
- questionnaire completeness
- contradictory responses
- agreement between questionnaire and AI conversation
- amount of supporting evidence

---

## Evidence

Evidence records how the signal was generated.

Possible evidence includes:

- standardized questionnaire
- adaptive follow-up questions
- conversational assessment
- clinician input
- longitudinal reassessment

A signal may contain multiple evidence sources.

---

## Source

The assessment instrument responsible for producing the signal.

Examples:

- BFI-2
- Adult Attachment Interview
- ERQ
- Conversation AI

---

## Quality

Overall quality estimate of the signal.

Possible values:

- High
- Medium
- Low

Quality differs from confidence.

Confidence estimates statistical certainty.

Quality reflects overall assessment integrity.

---

## Timestamp

Records when the signal was generated.

Allows longitudinal personality tracking in future NIROS versions.

---

## Metadata

Optional module-specific information.

Examples:

- questionnaire version
- language
- assessment duration
- missing responses
- scoring version

# Big Five Signals

The Big Five Module generates five primary Psychological Signals.

- Openness
- Conscientiousness
- Extraversion
- Agreeableness
- Neuroticism

Future versions may additionally generate fifteen facet-level signals corresponding to the BFI-2 facet structure.

# Multi-source Assessment

NIROS supports multiple independent estimates of the same psychological construct.

Example:

Questionnaire

↓

Openness = 74

Conversation Assessment

↓

Openness = 79

Adaptive Follow-up

↓

Openness = 77

The Reasoning Engine combines these independent signals into a unified psychological representation.

Individual module outputs are never overwritten.

Every source remains independently available for interpretation.

---

# Reasoning Engine Integration

The Reasoning Engine consumes Psychological Signals instead of questionnaire responses.

Its responsibilities include:

- integrating signals from multiple modules
- detecting agreement between assessment sources
- identifying conflicting evidence
- estimating overall confidence
- generating a unified psychological profile
- providing evidence-aware reasoning

This separation allows NIROS to continuously improve the psychological representation without modifying the original assessment results.

---

# Future Extensions

The data model is intentionally designed to support:

- repeated assessments over time
- longitudinal personality tracking
- AI-generated evidence
- clinician observations
- multimodal behavioural analysis
- physiological measurements
- wearable device integration
- future machine learning models

No structural changes should be required when new assessment modules are introduced.

---

# Summary

The Big Five Module does not produce isolated questionnaire scores.

It produces standardized Psychological Signals.

These signals become part of the unified NIROS Psychological Representation, where they are integrated with evidence generated by every other psychological assessment module.

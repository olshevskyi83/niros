# Sprint 001 — Human Understanding MVP

## Goal

Design and implement the text-based adaptive interview MVP.

## Scope

- State machine
- Question library
- Structured extraction
- Declared vs confirmed problem
- Risk screen
- Final profile JSON

## Not in scope

- Full voice streaming
- Sensor fusion
- Music generation
- Clinical claims

## Definition of done

- A user can complete an intake conversation.
- Output validates against HumanProfile schema.
- Risk signals interrupt normal flow.
- AI never claims diagnosis.
